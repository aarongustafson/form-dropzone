<form-dropzone>

Add file drag-and-drop, drop-result announcements, and optional image previews to a labeled native picker. See the README for installation and API documentation.

Read the README View on GitHub esm.sh example unpkg example

Your choice is saved for other component demos on this site that support tabs.

Using these examples Use the native file picker with the keyboard or drop files onto an enhanced zone. The picker keeps its browser focus indicator; the wrapper adds no tab stop. During a file drag, the dashed boundary becomes solid without changing the zone’s colors. If JavaScript or the required APIs are unavailable, the original label and picker remain. Rejected files are named in the status announcement; choose another file to recover. This page also uses shared message defaults; individual examples can override them.

Basic picker and label alternatives

The only required content is one file input and its associated label.

Associate the label with for

Without accept or multiple, the first dropped file is selected and any additional files are rejected with an accessible announcement. 

<form-dropzone>
  <label for="basic-file">Choose a file</label>
  <input
    id="basic-file"
    name="basic-file"
    type="file" />
</form-dropzone>
Selected: No files

Wrap the input in its label

The label can also contain the file input. Both patterns keep the native picker usable before registration or when drag-and-drop is unavailable. 

<form-dropzone>
  <label>
    Choose a spreadsheet
    <input
      name="spreadsheet"
      type="file"
      accept=".csv,.xlsx" />
  </label>
</form-dropzone>

Multiple files and accept

Set accept on the input to limit dropped file types. Add multiple to allow more than one file.

Mixed accept syntax

This input accepts PDF filenames, plain text MIME types, and any image MIME type. Drop a PDF and an audio file: the PDF replaces the previous selection, and the audio file is rejected and named in the announcement. A drop with no accepted files leaves the selection unchanged. 

<form-dropzone>
  <label for="mixed-files">Choose documents or images</label>
  <input
    id="mixed-files"
    name="mixed-files"
    type="file"
    accept=".pdf,text/plain,image/*"
    multiple />
</form-dropzone>

Image previews

Add preview-images to show image selections from the picker or a drop, with filenames below the images.

Multiple image preview grid

Select several images to see a grid of cropped previews. Selecting again replaces the previews. Non-image files can remain selected when allowed by the input, but only image MIME types get previews. 

<form-dropzone preview-images>
  <label for="preview-images">Choose images</label>
  <input
    id="preview-images"
    name="preview-images"
    type="file"
    accept="image/*"
    multiple />
</form-dropzone>

Localization and custom announcements

Rewrite the instructions and drop-result messages for your application’s vocabulary or language. Use {count} for the number of files in an outcome and {files} for their names. See the attribute reference for defaults and JavaScript properties.

Custom English announcements

Drop multiple PDFs plus a non-PDF file to produce received, file-type rejection, and single-file limit messages in one announcement. The visible result list uses form-dropzone:drop to show accepted files and both rejection categories without watching the live region. 

<form-dropzone
  id="english-announcements-zone"
  received-message="Ready to upload {count}: {files}."
  rejected-type-message="Not accepted: {files}. Choose a PDF."
  rejected-multiple-message="Only the first PDF was added. Extra: {files}.">
  <label for="custom-announcements">Choose one PDF</label>
  <input
    id="custom-announcements"
    name="custom-announcements"
    type="file"
    accept=".pdf" />
</form-dropzone>

Share complete messages across pickers

One authored JSON script supplies page-wide defaults. Message objects can use plural categories; other is required. The nearest lang selects a category, and a missing category falls back to other. An instance attribute still wins for that message.

Two instances, one configuration

Choose or drop one or several reports. The first zone uses the shared singular/plural announcement; the second overrides just that message. Drop outcomes are announced, while native picker selections keep native feedback. Clearing the form also clears previews and drop feedback. 

<script type="application/json" data-form-dropzone-config>
  {
    "received-message": {
      "one": "Received one file: {files}.",
      "other": "Received {count} files: {files}."
    }
  }
</script>

<form-dropzone>
  <label for="shared-reports">Choose reports</label>
  <input id="shared-reports" name="reports" type="file"
    accept=".pdf" multiple />
</form-dropzone>

<form-dropzone preview-images
  received-message="Reference images: {files}.">
  <label for="shared-references">Choose reference images</label>
  <input id="shared-references" name="references" type="file"
    accept="image/*" multiple />
</form-dropzone>

Style the picker and previews

Use author CSS to change alignment, borders, the native picker button, and previews. Keep the picker’s focus indicator and a drag cue that doesn’t depend on color.

Left-aligned circular previews

The picker button is purple, the content aligns to the start, and image previews are circular. During a file drag, the dashed border becomes solid. The picker stays visible with or without enhancement. 

<style>
  .custom-dropzone {
    display: block;
    align-items: start;
    background: Canvas;
    color: CanvasText;
    border: 3px dashed currentColor;
    border-radius: 1rem;
    min-block-size: 10rem;
    text-align: start;
  }

  .custom-dropzone.form-dropzone--drag-active {
    border-style: solid;
  }

  .custom-dropzone.form-dropzone--enhanced {
    display: flex;
  }

  .custom-dropzone input[type="file"] {
    background: transparent;
    color: inherit;
    border: 0;
    padding: 0;
  }

  .custom-dropzone input[type="file"]::file-selector-button {
    background: #4f3ca7;
    border: 1px solid currentColor;
    border-radius: 0.5rem;
    color: white;
    cursor: pointer;
    font: inherit;
    margin-inline-end: 0.75rem;
    padding: 0.65rem 1rem;
  }

  .custom-dropzone input[type="file"]::file-selector-button:hover {
    background: #392b7a;
  }

  .custom-dropzone .form-dropzone__previews {
    grid-template-columns: repeat(auto-fit, minmax(min(6rem, 100%), 1fr));
  }

  .custom-dropzone .form-dropzone__preview-image {
    border-radius: 50%;
    max-block-size: 200px;
    max-inline-size: 200px;
  }
</style>

<form-dropzone
  class="custom-dropzone"
  preview-images>
  <label for="styled-images">Choose profile images</label>
  <input
    id="styled-images"
    name="styled-images"
    type="file"
    accept="image/*"
